# Photos du site — Village 1800

Dépose ici tes photos (thème huile d'olive, olives, oliviers, terroir de Korba).
**Garde exactement les mêmes noms de fichiers** : elles apparaissent alors automatiquement,
sans toucher au code. Format conseillé : **JPG ou WebP**, paysage, ~2000 px de large, optimisées.

Si un fichier est absent, un dégradé élégant s'affiche à la place (rien ne casse).

| `oliveraie.jpg`   | Page **Notre histoire** (bandeau)        | Oliveraie / rangées d'oliviers au soleil |
| `olivier.jpg`     | Page **Notre histoire** (section vision) | Vieil olivier centenaire, écorce |
